# To-Do List

A simple command-line To-Do List application built with Python.

## Features

* Add tasks to the list
* Prevent duplicate tasks
* Remove tasks
* View all tasks
* Mark completed tasks
* View task progress
* Exit the program

## How It Works

When the program starts, it displays a menu with six options:

1. Add task
2. Remove task
3. View tasks
4. Update completed tasks
5. View progress
6. Exit

Tasks are stored in a Python list. The program keeps running until the user selects the Exit option.

## Requirements

* Python 3

## How to Run

1. Download or clone this repository.
2. Open the project folder in a terminal.
3. Run:

```bash
python todo.py
```
